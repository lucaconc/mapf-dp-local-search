# MovingAI MAPF benchmark (subset)

Maps from the MovingAI MAPF benchmark (Sturtevant, "Benchmarks for Grid-Based
Pathfinding", IEEE TCIAIG 2012; Stern et al., "Multi-Agent Pathfinding:
Definitions, Variants, and Benchmarks", SoCS 2019; https://movingai.com/benchmarks/mapf),
copied from the `scripts/map` folder of https://github.com/kei18/lacam3.

Official scenarios included: `random-32-32-20-random-1.scen` (from
https://github.com/Jiaoyang-Li/MAPF-LNS2) and `random-32-32-10-random-1.scen`
(from kei18/lacam3). The other scenario files in this folder whose name ends
in `-gen-<seed>.scen` are generated by `mapf_bench.movingai.generate_scen` in
the same format: distinct random starts and goals in the largest connected
component, as the official "random" scenarios.
